# ClipboardMerge

一个轻量 Windows 剪贴板工具，整合复制内容提示与连续复制合并。

## 使用

- 普通复制：每次复制后，在屏幕中下方显示复制内容预览约 1 秒。
- Win + Shift + C：开始或结束累积复制。
- 累积模式中继续正常使用 Ctrl + C，每次复制的文本按设定分隔符追加。
- 累积模式中随时按 Ctrl + V，都会粘贴当前已经合并的全部内容。
- Win + Shift + X：清空当前已经累计的内容，但继续保持累积模式。
- 托盘菜单可以清空当前累积、修改设置、控制开机自启或退出程序。

默认分隔符为换行，提示音关闭，复制提示持续 1 秒。
